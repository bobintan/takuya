# ブーストコンサルティング 説明会メモ（FDE）

## 1. FDE（Forward Deployed Engineer）とは
- 「点を線にしていく」エンジニア
- 流れ：**客先の業務理解 → 顧客先で実装 → AIが実際に使われるまでやりきる**
- 背景にある課題：SFAやデータレイクを導入したが**使われていない**企業が多い
- FDEは業務を理解し、AIが「無くてはならない」状態をつくる。**成果が出るまでコミット**する

## 2. 価値観
- AIによってアイデアは無限に出せる時代 → 価値は「**行動して業務を完了させる力**」
- 価値があるのは「売れる実績」「最後までやりきる人」
- 「思いついた・考えた」だけの人には価値がない

## 3. FDEに求められる4つの力
| 力 | 内容 |
|---|---|
| 本質を見抜く力 | 何を解くべきかを決める |
| 言語化する力 | 言葉・文字にする力（＝プロンプト力） |
| 見極める力 | 出力の良し悪しを判断する。良い答えを知らない人は良い答えを選べない |
| 人を動かす力 | プレゼン・対話・信頼構築。組織を動かすのはAIではなく人 |

**この4つを回すのがFDEの仕事**
> 現場で課題を見抜く → AIに言語化して渡す → 出力を見極める → デリバリー（人を動かして定着させる）

## 4. 求める人材像：事業理解 × AI実装力の「越境人材」
- 両利きの人材は日本にはほとんど居ない
- **コンサル・ビジネス出身**：「動くもの」で成果を出すコンサルになる必要がある
- **エンジニア出身**：課題を定義し、事業を動かすエンジニアになる必要がある

## 5. 過去のIT導入からの教訓
- **導入が目的化すると失敗する**
- 最重要は**KPIを改善すること**

## 6. 未経験者について
- エンジニア経験・開発経験がなくてもOK
- 一人ではなく、分かっている人とチームで客先に入る
- ブートキャンプで最低限の知識は身につけられる

## 7. 働き方
- 会社は創業期のため**原則オフィス出社**（リモートワークは基本なし）
- 急速かつ密度の高い環境でディスカッションしながら進めるため

## 自分用メモ：追加で確認したい点（候補）
- ブートキャンプの期間・内容（技術領域、使用ツール）
- 案件の業界・規模、1案件あたりの期間とチーム構成
- 成果（KPI改善）の評価方法と、それが報酬・評価にどう反映されるか
- 出社頻度の実態、客先常駐の有無
- 入社後の立ち上がりまでの期待値（何か月で独り立ちか）
